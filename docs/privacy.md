# Privacy, consent & transparency

## What is captured

| Data | Source | Where it goes |
|---|---|---|
| Meeting metadata (subject, time, attendees, invite body) | Team calendar via Microsoft Graph | SE Copilot database |
| Transcript | Recall.ai bot (platform captions or Recall ASR), or uploaded/pasted by an SE | Recall (processing), then SE Copilot database |
| SE notes | Typed by the SE | SE Copilot database |
| Analysis / MOM | Generated by Anthropic Claude from the above | Anthropic (processing), then SE Copilot database |
| Follow-up email | Built from the approved MOM | Sent through Microsoft 365 to the recipients the SE confirmed |

SE Copilot does not record or store audio or video from the notetaker. Recall may retain media according to your workspace settings; configure retention there.

## Transparency in the meeting

- The notetaker is a visible participant named as an AI notetaker; the name is validated so it can't pose as a person.
- It posts a configurable message in meeting chat when it joins.
- It joins only through the platform's guest flow: waiting rooms, lobbies, host recording-permission prompts and caption settings are all respected. If any of them blocks capture, the meeting shows *Meeting capture unavailable* and the SE falls back to notes or a transcript.
- "No AI" markers in the invite (subject or body; configurable list) keep the notetaker out, and an SE can switch it off per meeting.

## Consent

Consent law varies (one-party vs. all-party jurisdictions, GDPR lawful basis, customer contracts). SE Copilot provides the mechanisms: visible identity, join announcement, opt-out markers, per-meeting override. **Your organization decides the policy.** A common baseline is a line in the invite template ("An AI notetaker will join to take notes; reply if you'd prefer it doesn't"), plus honoring any objection by removing the bot from the call.

## Customer data in external communication

- Customer MOMs contain only customer-safe sections; internal risks, concerns and "interesting topics" stay internal.
- Nothing leaves SE Copilot without SE approval and confirmation (see [security.md](security.md)).
- Later phases (organization-wide insights, LinkedIn) will add the `PrivacyScanner` gate described in the product spec. The MVP has no path that publishes outside the customer thread.

## Data minimization

- Meetings the notetaker shouldn't attend (internal, personal/private, "No AI") are still detected so the SE can take notes, but no bot is sent.
- Only the configured team mailboxes are readable when the Graph app is scoped as documented.
